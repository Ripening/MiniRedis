## 写法建议

每篇回答三个问题:
1. **它解决什么问题**(没有它之前怎么办)
2. **它怎么做的**(机制、数据结构、关键代码位置)
3. **面试会怎么问 + 我怎么答**

第 3 条最重要——笔记的终点是能讲出来,不是能读懂。
